# Darna Concierge

IMPORTANT: Build a WEBSITE, NOT an app.

Create a premium, responsive marketing and concierge website for a Moroccan travel brand called “darna”.

DO NOT build:
- A mobile app
- A web app/dashboard
- Login/signup
- User accounts
- Airbnb-style marketplace
- Property availability system
- Online booking engine
- Fake property listings
- App-style bottom navigation

This is a premium CONCIERGE WEBSITE whose main goal is to make visitors contact darna through WhatsApp or the inquiry form.

==================================================
BRAND
==================================================

Brand name:
darna

Positioning:

“Your personal concierge for Morocco.”

Core concept:

The customer tells darna what they need.

They tell us:
- Where they want to go
- Their dates
- Number of people
- Accommodation requirements
- Activities they want
- Transportation they need
- Their budget

Then darna personally searches for suitable options and helps arrange everything.

The customer does NOT browse a marketplace of darna-owned properties.

Main message:

“TELL US WHAT YOU NEED. WE’LL FIND IT FOR YOU.”

Geographic focus:

Tangier · Tetouan · Chefchaouen

Also include:
